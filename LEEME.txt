PALCAZU TRAVEL — EDICIÓN PREMIUM

ARCHIVOS
- index.html: inicio
- destinos.html: ideas de destinos con filtros
- experiencias.html: tipos de experiencia
- nosotros.html: filosofía y turismo responsable
- contacto.html: formulario que prepara un correo en la aplicación del visitante
- preguntas.html: preguntas frecuentes
- styles.css: estilos compartidos y diseño adaptable a celular
- script.js: menú móvil, filtros, preguntas desplegables y efectos de entrada

PUBLICAR EN GITHUB PAGES
1. Descomprime el ZIP.
2. Sube todos los archivos anteriores directamente a la raíz del repositorio (no dentro de una carpeta).
3. Asegúrate de que el archivo principal se llame exactamente index.html.
4. Haz Commit changes. Espera unos minutos y abre tu URL de GitHub Pages.

IMPORTANTE
- Las fotos se cargan desde Unsplash y las tipografías desde Google Fonts; requieren conexión a internet.
- No se han inventado precios, teléfonos, correos empresariales ni servicios confirmados. Las tarjetas son ideas visuales y deben verificarse antes de vender un paquete.
- GitHub Pages sirve páginas estáticas. El formulario abre el correo del visitante y no guarda datos ni confirma reservas.
- Antes de usar comercialmente, añade los datos reales de contacto, servicios, precios, políticas y permisos correspondientes.
